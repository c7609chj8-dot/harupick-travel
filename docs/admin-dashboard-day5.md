# 관리자 대시보드 5일 차: 통합 검증과 운영 점검

검증일: 2026-11-26 (한국 시간)
상태: 5일 개발 일정 완료

## 검증한 사용자 흐름

관리자 로그인 → 대시보드 집계 조회 → 7일·30일 추이 선택 → 다가오는 일정 상세 → 일정 보관·복원 → 대시보드 자동 갱신 → 최근 변경의 전후 비교 → 로그아웃·권한 거부 시 데이터 제거를 점검했습니다.

이번 변경은 기존 자동 통합 테스트에 대시보드 경계를 추가하고 최종 검증 기록을 정리한 것입니다. 검증 범위에서 추가 제품 코드 수정이 필요한 결함은 발견되지 않았습니다. DB 스키마·인증 설정 변경은 없습니다.

DB 검증은 database/tests/harupick-dashboard-security.sql을 전체 실행했습니다. 기존 Auth 계정·세션을 사용하고 Auth 데이터를 생성하거나 변경하지 않았습니다. 하루픽 검증 데이터·권한 변경은 같은 트랜잭션에서 전부 롤백했습니다.

브라우저에서 사용한 회원·일정·통계는 로컬 모의 데이터입니다. 일정 저장·관리자 수정·감사 조회·회원 복사와 대시보드 간 데이터 전달은 tests/integration-flow.test.mjs에서 공식 SDK 요청으로 함께 검증합니다. 운영 관리자 비밀번호를 사용한 실제 브라우저 로그인은 수행하지 않았습니다.

4일 차에 검증한 모바일 390px, 0건, 날짜별 표의 키보드 조작, 지연 응답 무효화 동작도 자동 회귀 검사 범위와 함께 유지됩니다. 이번 단계에서 화면 코드는 변경하지 않았습니다.

## 운영 해석과 남은 사항

- 요약 카드는 현재 상태·고정 기간 기준이며, 7일·30일 선택은 추이에 적용됩니다.
- 회원 등록 추이는 현재 가입 완료 회원의 하루픽 프로필 등록일입니다. 방문자·접속 횟수 지표가 아닙니다.
- 삭제·인증 완료 등에 따라 과거 날짜의 수치도 달라질 수 있습니다. 불변의 역사 통계가 필요하면 별도 집계 저장 설계가 필요합니다.
- 실제 메일 전달, 인증 링크 완료, 실제 비밀번호 변경은 검증하지 않았습니다. 기존 시범 운영 안내와 공유 Auth 설정을 유지합니다.
- 이전 관리자 최종 검증 문서는 당시 결과를 보존합니다. 대시보드 포함 최신 검증 수치는 이 문서를 기준으로 확인합니다.

## 재실행

```powershell
node scripts/check-site.mjs
node --test tests/*.test.mjs
node scripts/smoke-production.mjs
```

실제 DB 회귀 SQL은 기존 관리자 활성 세션·일반 Auth 계정이 있는 상태에서 전체 트랜잭션을 실행해야 합니다. 파일 끝의 ROLLBACK을 제거하거나 일부 쓰기 구문만 별도 실행하지 않습니다.
