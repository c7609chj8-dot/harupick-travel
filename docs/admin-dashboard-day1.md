# 관리자 대시보드 1일 차: 지표 정의와 화면 구성

상태: 1일 차 완료 / 통계 API 연결 전
작성일: 2026-11-26 (한국 시간)
화면: admin.html의 관리자 인증 후 대시보드 구역

## 목표와 범위

관리자가 회원 등록 현황, 서버에 저장된 여행 일정, 가까운 여행, 운영 변경 이력을 한눈에 확인하도록 구성합니다.

1일 차에는 집계 기준과 API 응답 계약을 정하고 관리자 화면에 배치 초안을 연결합니다. 현재 숫자·목록·차트 통계는 조회하지 않습니다. 집계하지 않은 값을 0으로 표시하지 않으며 예시 숫자도 넣지 않습니다. 회원·일정·감사 관리의 기존 기능은 계속 사용합니다.

## 공통 모집단과 시각

- 시간대는 Asia/Seoul입니다. 서버가 반환한 as_of를 모든 카드·목록의 공통 기준 시각으로 사용합니다.
- 하루는 한국 시간 00:00 이상, 다음 날 00:00 미만입니다.
- 가입 완료 회원은 harupick_members와 auth.users를 ID로 연결해 email_confirmed_at이 있고 deleted_at이 없는 계정입니다. 이용 제한된 계정도 가입 완료 회원 수에는 포함합니다.
- 관리자 권한만 있고 하루픽 프로필이 없는 계정은 회원 수에 포함하지 않습니다. 교육 서비스 계정만 있는 사용자도 제외합니다.
- 집계 대상 일정은 harupick_trips에 저장되어 있고 소유자의 하루픽 프로필과 삭제되지 않은 Auth 계정이 존재하는 일정입니다. 소유자의 이메일 미인증·이용 제한 여부로 기존 저장 일정을 숨기지는 않습니다.
- 브라우저 localStorage의 일정은 집계 대상이 아닙니다.
- 서버 일정 한 행을 한 건으로 셉니다. 다른 기기에서 복사한 뒤 별도 서버 일정으로 저장한 복사본은 다른 한 건입니다.
- 감사 이력은 보존된 audit_events 기준입니다. 대상이 삭제되어도 남아 있는 기록을 포함합니다.
- 공유 Auth 계정의 last_sign_in_at은 하루픽 방문자 수·방문 횟수 지표로 사용하지 않습니다.

## 핵심 지표

| 지표 / 응답 키 | 정의 | 제외·표시 기준 |
| --- | --- | --- |
| 가입 완료 회원 / registered_members | 공통 모집단의 가입 완료 회원 수 | 관리자 권한 보유 여부와 독립적. 인증 대기 계정·삭제된 계정 제외 |
| 전체 서버 일정 / total_trips | 집계 대상 서버 일정 전체 수 | active와 archived 모두 포함. 보조 수치 active_trips + archived_trips와 항상 일치 |
| 다가오는 여행 / upcoming_trips_30d | status=active이고 여행 날짜가 한국 시간 오늘부터 D+29까지인 일정 수 | 오늘 포함 30개 날짜. 날짜 미정·지난 날짜·보관 일정 제외. 여행자 수가 아닌 일정 수 |
| 최근 7일 변경 / changes_7d | 오늘을 포함한 한국 시간 최근 7개 날짜의 감사 이벤트 수 | trip.*와 admin.*의 성공한 변경만 포함. 로그인·실패 요청·기록 기능 적용 전 변경 제외 |

카드 1~3은 현재 상태이며 기간 필터로 변하지 않습니다. 4번 카드는 고정된 최근 7개 날짜의 이벤트 수입니다. 7일·30일 선택은 추이 차트에만 적용합니다.

## 목록과 차트

| 구역 | 기준 | 정렬·개수 | 표시 정보 |
| --- | --- | --- | --- |
| 다가오는 여행 | upcoming_trips_30d와 같은 조건 | travel_date 오름차순, id 오름차순 / 최대 5개 | 일정 제목, 여행 날짜, 소유자 닉네임, 일정 ID |
| 최근 변경 이력 | 보존된 감사 이벤트 전체 | occurred_at 내림차순, id 내림차순 / 최대 5개 | 작업 유형, 시각, 수행자 표시 이름·유형, 대상 제목, 기록 ID |
| 회원 등록 추이 | 현재 가입 완료 회원의 하루픽 프로필 created_at 날짜 | 오늘 포함 7일 또는 30일, 날짜 오름차순 | 날짜와 건수. 누락 날짜는 실제 집계 결과 0으로 채움 |
| 일정 생성 추이 | 현재 집계 대상 서버 일정의 created_at 날짜 | 동일 기간, 동일 정렬 | 날짜와 건수. active·archived 모두 포함 |

회원 등록 추이는 Auth 계정의 최초 생성일이 아닙니다. 인증 완료 후 과거 프로필 등록일의 수치가 추가될 수 있습니다. 삭제된 프로필·일정은 현재 모집단에서 빠지므로 추이는 과거 시점의 불변 스냅샷이 아닙니다. 최근 변경 기록 목록은 최근 7일 카드와 달리 기간 제한 없이 최신 5개를 표시합니다.

이메일, 전체 회원 목록, 일정 메모, 인증 토큰은 대시보드 응답에 넣지 않습니다. 상세 정보는 기존 관리자 관리 화면에서 별도로 조회합니다.

## 화면 배치

1. 관리자 확인·현재 계정·로그아웃 영역
2. 대시보드 제목, 집계 기준 시각 자리, 연결 상태 안내
3. 요약 카드 4개: 데스크톱 4열 / 중간 화면 2열 / 모바일 1열
4. 회원 등록·일정 생성 추이 영역
5. 다가오는 여행 5개와 최근 변경 5개: 데스크톱 2열 / 모바일 1열
6. 회원 관리·일정 관리·변경 이력으로 이동하는 링크
7. 기존 권한 정보와 회원·일정·감사 관리 기능

1일 차의 통계 값은 '집계 준비 중', 목록과 차트는 연결 전 안내입니다. 기존 관리 기능으로 이동하는 링크만 동작합니다.

## 상태 규칙

| 상태 | 화면 |
| --- | --- |
| 연결 전 / not_connected | 집계 준비 중. 숫자·목록·갱신 시각을 표시하지 않음 |
| 로딩 / loading | 집계 중 안내. 이전 계정의 통계는 즉시 제거 |
| 정상 / ready | 서버가 검증된 숫자·목록·as_of를 반환한 뒤 표시 |
| 데이터 없음 | ready 안에서 실제 0, 빈 목록, 날짜별 0을 표시 |
| 오류 / error | 통계 조회 실패와 재시도 안내. 오류를 0으로 바꾸지 않음 |
| 권한 없음 / signed-out 또는 denied | 관리자 콘솔을 숨기고 표시했던 통계를 제거 |

기준 시각과 권한 확인 시각은 별개입니다. 단순 권한 재확인 시각을 데이터 갱신 시각으로 표시하지 않습니다. 권한 회수·계정 전환·탭 복귀 시 기존 접근 제어와 요청 응답 무효화 규칙을 적용합니다.

## 2일 차 API 계약

예정 RPC: public.harupick_admin_dashboard(p_days integer default 7)

- p_days는 7 또는 30만 허용합니다.
- public의 SECURITY INVOKER 래퍼와 비공개 스키마의 집계 함수를 사용합니다.
- 서버는 기존 is_current_admin()으로 현재 권한·이메일 인증·계정 상태·실시간 세션을 확인합니다.
- anon은 실행 불가, 일반 authenticated 회원은 42501로 차단합니다.
- 집계는 서버에서 수행합니다. 모든 회원·일정 행을 브라우저로 받아 세지 않습니다.
- 같은 기준 시각과 읽기 스냅샷으로 카드·목록·추이를 반환합니다.
- 성공 응답은 아래 형태를 따릅니다. 오류는 RPC 오류로 반환하며 metrics를 0으로 채운 성공 응답을 만들지 않습니다.

```text
as_of: ISO 8601 timestamp
timezone: "Asia/Seoul"
trend_days: 7 | 30
trend_from: YYYY-MM-DD
trend_until: YYYY-MM-DD  // 포함되는 마지막 한국 날짜
metrics:
  registered_members: nonnegative integer
  total_trips: nonnegative integer
  active_trips: nonnegative integer
  archived_trips: nonnegative integer
  upcoming_trips_30d: nonnegative integer
  changes_7d: nonnegative integer
upcoming_trips: [{ id, title, travel_date, nickname }]  // 최대 5개
recent_changes: [{ id, event, occurred_at, actor_label, actor_type, target_label }]  // 최대 5개
trends:
  member_registrations: [{ date, count }]  // trend_days개
  trip_creations: [{ date, count }]       // trend_days개
```
