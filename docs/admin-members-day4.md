# 회원관리 테이블 4일 차: 상세 화면과 목록 복귀

작성일: 2026-11-26 (한국 시간)
상태: 4일 차 구현·검증 완료
화면: admin.html 관리자 인증 후 회원 상세

## 구현 내용

- 상세 정보를 ‘계정 정보’와 ‘등록·인증 시각’으로 구분했습니다. 기존 API와 조회 전용 권한을 유지합니다.
- 계정 정보는 닉네임·이메일·전체 회원 ID·계정 상태를 표시합니다. 시각은 하루픽 가입·프로필 수정·이메일 인증·최근 계정 로그인을 구분합니다.
- 시각 값은 한국 시간으로 표시하고 유효한 값에는 time/ datetime 의미 정보를 연결했습니다. 이메일이 없으면 이메일 없음, 인증이 없으면 미인증, 로그인 기록이 없으면 기록 없음으로 표시합니다.
- 최근 계정 로그인에는 다른 서비스의 공유 인증 로그인도 포함될 수 있으며 하루픽 방문 기록과 다르다는 설명을 유지·명확화했습니다.
- 선택한 회원의 닉네임과 선택 당시 페이지를 상세 상단에 표시합니다. 목록의 선택 행을 강조하고 상세 버튼의 aria-controls·aria-expanded를 연결했습니다.
- 상단 상세 닫기와 하단 회원 목록으로 돌아가기 버튼은 모두 선택한 회원의 원래 버튼에 포커스를 돌려줍니다. 해당 버튼이 사라지면 검색 입력칸으로 복귀합니다.
- 상세 영역에 포커스가 있을 때 Esc로 닫을 수 있습니다. 검색 폼 등 다른 영역의 Esc 동작을 가로채지 않습니다. 상세는 비모달 영역이며 포커스를 가두지 않습니다.
- 열기·재시도는 상세 제목에 포커스를 놓습니다. 고정 헤더와 사이트의 기본 부드러운 스크롤에 가려지지 않도록 대상을 즉시 드러냅니다. 응답 완료 시 다른 곳으로 이동한 포커스를 다시 빼앗지 않습니다.
- 상세 열기·닫기는 목록을 다시 조회하거나 필터·정렬·페이지를 초기화하지 않습니다.
- 조회 중·오류·회원 없음 상태에서는 이전 회원의 계정·날짜 값을 비우고 내용 영역을 숨깁니다. 권한 거부·접근 해제 시 선택 이름·페이지 문맥·날짜 값·회원 행도 제거합니다.
- 긴 이메일·닉네임·회원 ID는 말줄임 없이 줄바꿈하며, 모바일은 정보 영역을 한 열로 표시합니다.
