# 관리자 기능 최종 검증

검증일: 2026-11-26 (한국 시간)

하루픽의 회원 인증 → 회원별 일정 저장 → 관리자 조회·수정 → 감사 이력 → 회원 일정 복사 흐름을 점검했습니다.

모의 브라우저 검증에서는 실제 Auth 계정·메일을 생성하거나 비밀번호를 변경하지 않았습니다. DB 검증은 기존 세션을 요청 컨텍스트로 사용하며, 하루픽 검증 데이터와 권한 변경은 전체 롤백했습니다.

## 운영상 남은 사항

- 실제 메일 수신과 메일 링크의 계정 인증, 실제 비밀번호 변경은 이번 검증에서 실행하지 않았습니다. 따라서 외부 메일 전달까지 검증 완료로 간주하지 않습니다. 화면의 시범 운영·일부 이메일 제한 안내를 유지합니다.
- Supabase 보안 진단의 기존 유출 비밀번호 보호 비활성화 경고가 남아 있습니다. 공유 프로젝트의 다른 서비스에 영향을 주는 Auth 설정은 이번 배포에서 변경하지 않았습니다.
- 브라우저 일정과 서버 일정은 별도입니다. 각 일정의 ‘계정에 저장’ 버튼으로 저장하며 이후 편집도 다시 저장해야 합니다.
- 서버 일정을 ‘브라우저로 복사’하면 기존 일정과 별개인 새 복사본이 생깁니다. 복사본은 로그아웃 후에도 기기에 남습니다.
- 관리자 수정·보관은 서버 일정에 적용됩니다. 이미 복사한 브라우저 일정은 자동 변경되지 않습니다.
- 감사 로그는 기록 기능 적용 이후 성공한 일정·권한 변경만 포함합니다. 실패 요청·로그인은 이 목록의 범위가 아닙니다.

## 재실행

프로젝트 루트에서 다음 명령을 실행합니다. 외부 패키지 설치 없이 Node.js로 실행합니다.

```powershell
node scripts/check-site.mjs
node --test tests/*.test.mjs
node scripts/smoke-production.mjs
```

DB 검증은 database/tests/harupick-audit-security.sql 전체를 실행합니다. 기존 관리자 실시간 세션과 별도의 기존 Auth 계정이 필요하며 결과 데이터는 롤백됩니다.
