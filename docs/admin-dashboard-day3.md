# 대시보드 3일 차: 실제 카드·목록 연결

작성일: 2026-11-26 (한국 시간)
상태: 카드·목록 연결 완료 / 추이 차트·기간 선택은 4일 차

## 연결한 화면

- 관리자 권한 확인 후 getDashboard(7)로 서버 집계를 조회합니다.
- 가입 완료 회원, 전체 서버 일정, 30일 내 여행, 최근 7일 변경을 단위와 함께 표시합니다.
- 전체 서버 일정 아래에 이용 중·보관 건수를 별도로 표시합니다.
- 집계 기준 시각은 API의 as_of를 한국 시간으로 변환해 표시합니다. 권한 확인 시각을 집계 시각으로 사용하지 않습니다.
- 다가오는 여행과 최근 변경은 각각 최대 5개를 표시합니다.
- 요약 항목의 ‘일정 상세’와 ‘변경 전후’는 해당 ID로 기존 관리자 상세 API를 조회합니다. 목록 페이지를 찾아다닐 필요가 없습니다.
- 관리자 일정 변경을 저장하면 대시보드도 다시 조회합니다. 다른 운영자의 변경은 ‘통계 새로고침’으로 확인합니다.

## 상태와 접근 제어

| 상태 | 카드·목록 | 기준 시각·동작 |
| --- | --- | --- |
| 권한 확인 전 | 카드 —, 목록 비움 | 기준 시각 없음, 조회 비활성 |
| 로딩 | 이전 카드·목록 제거 후 집계 중 안내 | 기준 시각 제거, 중복 클릭 비활성 |
| 정상 | 서버 수치와 목록 표시 | 서버 as_of 표시, 새로고침 가능 |
| 실제 0건 | 0명·0개·0건, 빈 목록 안내 | 정상 응답의 기준 시각 표시 |
| 오류 | 카드 —, 목록 조회 실패 안내 | 기준 시각 제거, 재시도 제공 |
| 로그아웃·권한 회수 | 전체 관리자 콘솔 숨김, 카드·목록 제거 | 이전 응답은 무효화 |

요청 버전을 비교해 오래된 새로고침 결과, 계정 전환 전 결과, 로그아웃 전에 시작한 결과가 화면을 다시 채우지 못하도록 합니다. API 계약 검증 오류도 0건으로 처리하지 않습니다.

모든 제목·닉네임·수행자·대상 이름은 textContent로 표시합니다. API가 반환한 ID만 기존 상세 조회에 전달하며 상세 API의 서버 권한 검사도 유지합니다.

## 검증

- 기존 API 계약 테스트와 신규 대시보드 상태 처리 테스트 7개를 포함한 전체 자동 테스트 62개 통과.
- 정적 검증: HTML 9개, JavaScript 39개, 로컬 참조 218개 통과.
- 모의 서버와 브라우저에서 정상 수치·목록·기준 시각 표시 확인.
- 실제 0건 형태의 응답에서 0명·0개·0건과 빈 목록 안내 확인.
- 오류 시 카드와 시각 제거, 재시도 버튼 확인.
- 정상 통계의 일정·감사 요약에서 해당 상세가 열리는 동작 확인.
- 일정 보관 저장 후 이용 중·보관·다가오는 여행·변경 건수 자동 갱신 확인.
- 권한 회수와 느린 응답 도중 로그아웃 후 카드·목록이 다시 나타나지 않음 확인.
- 제목·수행자에 HTML 문자열을 넣어도 요소로 실행되지 않음 확인.
- 데스크톱 카드 4열 및 390px 모바일 1열, 가로 넘침 없음 확인.

브라우저의 정상·오류·지연 시나리오는 모의 서버로 검증했습니다. 실제 Auth 계정·메일·비밀번호를 변경하지 않았습니다. 서버 집계와 권한 검증은 [2일 차 결과](admin-dashboard-day2.md)를 유지하며 이번 작업에는 DB 스키마 변경이 없습니다.
