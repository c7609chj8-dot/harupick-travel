# 회원관리 테이블 5일 차: 통합 검증과 운영 점검

검증일: 2026-11-26 (한국 시간)
상태: 회원관리 5일 개발 일정 완료

## 결과와 변경 범위

회원 목록 → 검색·상태·가입 기간·정렬 → 페이지 이동 → 회원 상세 → 원래 행 복귀와 오류 복구·권한 해제 흐름을 함께 점검했습니다. 이번 단계는 SDK·컨트롤러 통합 회귀 테스트 2개를 추가하고 최종 검증 기록을 정리했습니다. 점검 범위에서 추가 제품 코드 수정이 필요한 결함은 발견되지 않았습니다. DB 스키마·함수·인증 설정 변경은 없습니다.

신규 자동 통합 테스트는 실제 Supabase JavaScript SDK와 실제 회원 클라이언트·컨트롤러를 사용하고 HTTP 응답만 모의 처리합니다. 모의 서버의 권한 판단을 실제 DB 보안 검증으로 간주하지 않습니다. 실제 권한 검사는 아래 DB 회귀 SQL로 별도 확인했습니다.

## 실제 DB 확인

- 기존 ai-education-hub-dev 프로젝트에서 database/tests/harupick-members-filter-security.sql 전체를 실행해 PASS를 확인했습니다.
- 기존 관리자 활성 세션·별도의 기존 Auth 계정을 요청 문맥으로 사용했습니다. 실제 사용자 비밀번호·토큰을 브라우저로 가져오지 않았습니다.
- 시작일 00시, 종료일 마지막 마이크로초와 다음 날 00시를 구분했습니다. 상태·날짜 조건을 적용한 전체 건수와 페이지가 일치했습니다.
- 기본값은 기존 회원 목록 API와 같은 결과였습니다. 같은 시각의 ID 정렬, 결과 0건과 마지막 페이지 보정도 확인했습니다.
- 권한 회수·일반 회원·종료 세션·익명 조회와 비공개 함수 직접 호출을 차단했습니다.
- 검증용 하루픽 프로필·권한 변경은 전부 ROLLBACK했습니다. Auth 사용자·자격 증명·세션은 생성하거나 변경하지 않았습니다.
- 상태 검증은 기존 계정의 실제 상태별 예상 수와 비교합니다. 존재하지 않는 상태는 0건으로 확인하며, 이를 위해 계정을 제한·삭제·인증 처리하지 않습니다. 클라이언트 모의 테스트는 네 가지 상태를 모두 포함합니다.

## 브라우저 통합 확인

- 한국 날짜 11월 24~26일·오래된 순 적용 후 두 번째 페이지에서 Enter로 상세를 열고 Esc로 복귀했습니다. 선택한 회원과 페이지 문맥·정렬·적용 조건이 일치했습니다.
- 상태를 바꾸기만 한 상태에서는 새로고침 후에도 기존 적용 조건과 두 번째 페이지를 유지했습니다. 조건 적용을 누르면 이용 가능 회원 16명·첫 페이지로 전환했습니다.
- 목록 오류 후 입력 중인 검색어를 바꿔도 재시도는 마지막 적용 검색어·상태·날짜·정렬을 사용했습니다. 결과 1명에서 상세를 열고 목록으로 복귀했습니다.
- 전체 초기화 후 미래 시작일만 적용하면 실제 0건 안내와 표 숨김을 표시했습니다. 상세에 이전 회원 정보가 남지 않았습니다.
- 회원 없음은 조회 오류와 별도 안내로 표시하고 목록으로 복귀할 수 있었습니다.
- 상세 API의 권한 거부 후 콘솔·상세를 숨기고 이름·계정·날짜·회원 행·검색어·적용 조건을 제거했습니다.
- 상세를 연 상태에서 로그아웃하면 콘솔·상세·모든 상세 값과 회원 행을 제거하고 로그인 안내로 돌아갔습니다.
- 콘솔 오류 없음. 검증 숫자·회원·이메일은 모두 로컬 모의 데이터입니다.

모바일 390px의 긴 값 전체 표시, 키보드 포커스 위치, 상세 재시도와 닫은 뒤 늦은 응답 무효화는 [4일 차 검증](admin-members-day4.md)에 기록되어 있습니다. 해당 제품 코드는 이번 단계에서 변경하지 않았습니다.

## 운영 점검과 검증 한계

- GitHub main과 연결된 Vercel 운영 배포의 커밋·READY 상태와 운영 별칭을 확인합니다.
- scripts/smoke-production.mjs에서 운영 페이지·자산 68개 HTTP 200과 보호 RPC 7개 익명 접근 차단을 확인했습니다. 신규 회원 필터 API와 기존 목록 API를 모두 포함합니다.
- 운영 브라우저에서 로그인 전 관리자 콘솔·상세 숨김, 회원 행·계정·날짜 값 0개와 빈 조건 요약을 확인했습니다. 콘솔 오류 없음.
- 실제 관리자 계정으로 운영 사이트에 로그인하는 브라우저 검증은 수행하지 않았습니다. 실제 메일 전달·인증 링크 완료·비밀번호 변경도 이 검증의 범위가 아닙니다.
- 회원 목록은 조회 전용입니다. 삭제·이용 제한·비밀번호 변경·관리자 권한 부여 기능을 추가하지 않았습니다.
- 공유 인증의 최근 로그인은 하루픽 방문 기록이 아닙니다. 회원 목록 수에는 인증 대기·이용 제한 등이 포함될 수 있어 대시보드 가입 완료 회원 수와 다를 수 있습니다.
- 실제 대규모 데이터의 부하 성능은 측정하지 않았습니다. 운영 계정 변경·메일 전달 등 기존 운영 제한은 [기존 관리자 검증](admin-release-verification.md)을 참고합니다.

## 재실행

```powershell
node scripts/check-site.mjs
node --test tests/*.test.mjs
node scripts/smoke-production.mjs
```

DB 회귀 SQL은 기존 관리자 활성 세션·일반 Auth 계정이 있는 상태에서 파일 전체를 실행해야 합니다. 마지막 ROLLBACK을 제거하거나 쓰기 구문만 따로 실행하지 않습니다.
