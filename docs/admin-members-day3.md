# 회원관리 테이블 3일 차: 필터·정렬 화면 연결

작성일: 2026-11-26 (한국 시간)
상태: 3일 차 구현·로컬 검증 완료
화면: admin.html 관리자 인증 후 회원 관리

## 구현 내용

- 계정 상태, 가입 시작일·종료일, 가입일 최신순·오래된 순 선택을 2일 차 필터 API에 연결했습니다.
- 닉네임·이메일 검색과 필터는 같은 폼의 ‘검색·조건 적용’ 또는 검색 입력칸의 Enter로 적용합니다. 적용 시 첫 페이지로 이동합니다.
- 적용한 검색어·상태·가입 기간·정렬을 목록 위에 표시합니다. 날짜는 한국 시간의 하루픽 프로필 등록일이며 시작일·종료일을 포함합니다.
- 입력 중인 조건과 실제 적용한 조건을 분리했습니다. 변경만 하고 적용하지 않으면 안내를 표시하며 기존 목록·요약을 유지합니다.
- 페이지 이동·목록 새로고침·오류 재시도는 마지막 적용 조건을 사용합니다. 입력 중인 값이 조회에 섞이지 않습니다.
- 초기화는 검색어·상태·날짜·정렬·유효성 오류를 기본값으로 되돌리고 첫 페이지를 조회합니다.
- 상태·기간 조건만 적용한 경우도 ‘검색 결과 N명’으로 표시합니다. 정렬만 바꾼 경우는 ‘전체 N명’을 유지합니다.
- 목록 설명·표 캡션·aria-sort를 실제 적용한 정렬에 맞춥니다.
- 기간 역전과 브라우저의 잘못된 날짜 입력은 API 호출 전에 차단합니다. 기존 적용 조건과 목록은 그대로 유지하고 수정할 위치를 안내합니다.
- 실제 0건, 조회 중, 서버 오류를 구분합니다. 서버 오류는 이전 목록을 지우고 적용 조건을 유지해 재시도할 수 있게 합니다.
- 권한 거부·로그아웃·계정 변경 시 기존 회원 행과 적용 조건 요약, 폼의 검색어·필터를 제거합니다. 일시적인 탭 이탈 후 권한 재확인 시에는 기존 조회 조건을 유지합니다.
- 모바일에서 조건 입력은 한 열로, 검색 입력은 한 줄 전체 너비로 표시합니다. 버튼과 필드는 키보드와 화면 읽기 도구로 접근할 수 있습니다.
