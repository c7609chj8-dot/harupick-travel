# 관리자 대시보드 4일 차: 기간 선택과 추이 차트

작성일: 2026-11-26 (한국 시간)
상태: 구현·로컬 검증 완료

## 구현 범위

- 최근 7일·30일 선택을 기존 통계 RPC의 p_days에 연결했습니다. 오늘을 포함한 한국 날짜 기준입니다.
- 회원 등록·서버 일정 생성 건수를 별도 SVG 막대 차트로 표시합니다. 두 차트의 세로축은 각각의 건수에 맞춰 정수 눈금을 사용합니다. 서로 다른 축이므로 막대 높이로 두 지표를 직접 비교하지 않습니다.
- 선택 기간 합계, 시작·종료 날짜, 정확한 날짜별 수치 표를 제공합니다. 표는 키보드 Enter로 열 수 있고 SVG에는 제목·기간·합계 설명을 연결했습니다.
- 선택 기간은 추이에만 적용됩니다. 요약 카드의 현재 상태·고정 기간 정의는 유지됩니다. 새 조회 시점의 실제 데이터 변경은 카드에 반영됩니다.
- 회원 등록은 현재 가입 완료 회원의 하루픽 프로필 등록일, 일정 생성은 현재 서버 일정의 생성일 기준입니다. 삭제·인증 완료에 따라 과거 수치가 달라질 수 있습니다.
- 조회 중·오류·권한 해제 시 기존 차트와 수치 표를 제거합니다. 실제 0건만 0건 안내와 높이 0 막대를 표시합니다.
- 빠른 기간 전환은 마지막 요청만 반영합니다. 새로고침·오류 재시도·일정 변경 후 조회는 선택 기간을 유지하고, 로그아웃·계정 전환은 7일로 초기화합니다.
- 모바일에서는 차트를 한 열로 배치합니다. 외부 차트 라이브러리와 DB 변경은 없습니다.

## 검증 결과

- 전체 Node 테스트 70개 통과. 차트 0건·정수 눈금·30일 끝점·급증·큰 정수·잘못된 입력과 기간 유지·초기화·응답 역전 테스트를 포함합니다.
- 정적 검사: HTML 9개, JavaScript 40개, 로컬 참조 219개 통과.
- 모의 관리자 브라우저: 7일 회원 등록 합계 13명에서 30일 23명으로 전환, 표 7행·30행, 차트 2개, 카드 값 유지 확인. 이 숫자는 로컬 모의 데이터이며 운영 데이터가 아닙니다.
- 오류 재시도 시 선택 기간 유지, 차트·표 제거, 카드 대시 표시 확인.
- 0건 모드에서 전체 막대 높이 0, 30개 날짜 행과 빈 데이터 안내 확인.
- 지연된 7일 응답 이후에도 30일 선택과 표 30행 유지 확인.
- 키보드 Enter로 날짜별 수치 표 펼침 확인.
- 390px 모바일에서 차트 한 열과 페이지 가로 넘침 없음 확인.
- 로그아웃 후 콘솔 숨김, SVG·표 행 제거, 기간 7일 초기화 확인.
- 모의 정상·0건·오류·지연 응답 검증 중 브라우저 콘솔 오류 없음. 실제 관리자 비밀번호를 사용하지 않았습니다.
