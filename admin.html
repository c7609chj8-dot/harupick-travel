      MEMBER DIRECTORY

      회원 관리

      하루픽 프로필이 있는 회원의 정보를 조회합니다.

      조회 전용 닉네임·이메일·하루픽 가입일·계정 상태를 확인하고, 상세 보기에서 추가 정보를 조회합니다.

      하루픽 가입일은 프로필 등록 시각입니다. 모든 시각은 한국 시간으로 표시합니다.

      계정 상태 표시 기준
      이용 가능
      삭제·이용 제한 상태가 아니며 이메일 인증이 완료된 계정
      이메일 미인증
      이메일 인증이 완료되지 않은 계정
      이용 제한
      서버에서 이용 제한 기간이 적용 중인 계정
      삭제된 계정
      인증 계정이 삭제 상태이고 하루픽 프로필이 남아 있는 계정
      확인 필요
      서버의 상태 값을 확인할 수 없는 경우

      상태가 겹치면 삭제 → 이용 제한 → 이메일 미인증 순서로 표시합니다. 관리자 권한은 별도이며 이 상태로 판단하지 않습니다.

      회원 조회 조건

      가입일은 하루픽 프로필 등록일입니다. 시작일과 종료일을 포함하며, 비워 두면 해당 날짜 제한을 적용하지 않습니다.

      조건을 변경했습니다. 검색·조건 적용을 눌러 목록에 반영해 주세요.

      표를 좌우로 밀면 계정 상태와 상세 보기까지 확인할 수 있습니다.

      등록·인증 시각

      모든 시각은 한국 시간입니다. 최근 계정 로그인은 같은 인증 계정을 사용하는 다른 서비스의 로그인도 포함할 수 있으며, 하루픽 방문 기록과는 다릅니다.

      상세 영역에서 Esc를 누르면 선택한 회원 행으로 돌아갑니다.

      TRIP MANAGEMENT

      여행 일정 관리

      회원이 계정에 저장한 일정만 표시됩니다. 브라우저에만 있는 일정은 포함되지 않습니다.

      좁은 화면에서는 표를 좌우로 밀어 조회·관리 버튼까지 확인할 수 있습니다.
